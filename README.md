# find-a-spot

Мини-игра на реакцию, где задача игрока заключается в том, чтобы найти скрытую точку менее чем за 2 секунды.

## Описание проекта

Find a Spot — это легкая браузерная игра, проверяющая скорость поиска  пользователя. Точка появляется в случайном месте экрана. Проект демонстрирует навыки работы с таймерами, случайной генерацией координат и обработкой событий мыши в JavaScript.

---

## Стек технологий

- **HTML5** — базовая структура игрового поля
- **CSS3** — стилизация элементов, адаптивное позиционирование и визуальные эффекты
- **JavaScript (ES6+)** — игровая логика, генерация случайных координат, таймеры и обработка кликов

---

## Запуск локально

Проект является полностью статическим и не требует установки зависимостей (Node.js, npm и т.д.).

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Kievsky332/find-a-spot.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd find-a-spot
   ```
3. Откройте файл index.html двойным кликом в любом современном браузере.
